# Sketch Manifest

## Design Direction

Chatbot-first layout that starts as a clean, centered interface. Upon flight search queries, it dynamically transitions into a split-screen view: the chatbot smoothly slides to the left (~35%), while the main right area (~65%) expands to display clean, separate flight cards. Uses purple brand accents (#7C5CFC) with white surfaces and light borders.
