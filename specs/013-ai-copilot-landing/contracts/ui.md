# Public Landing UI Contract

| Element           | Required behavior                                                                              |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| Root route        | Renders the AI Flight Copilot public landing page at `/`.                                      |
| Primary action    | A semantic link labelled `Log in` navigates to `/login`.                                       |
| Secondary action  | A semantic link labelled `Create account` navigates to `/register`.                            |
| AI messaging      | Describes guidance and personalization only; does not promise AI booking or payment execution. |
| Responsive layout | At 375px and 1440px, primary content remains visible without horizontal overflow.              |
